Urban Vila Guilherme, Torre A, apto 0306. Preço nominal: R$ 276.804,89. Financiamento previsto: R$ 195.770,80. Entrega prevista: 31/10/2029. NÃO CONFIRMADO
O pagamento do sinal de R$ 800 NÃO é marcado como quitado automaticamente. A prestação do banco é inicialmente zero por não estar definida. A renda é configurável e deve ser revisada. Índices de correção não são aplicados automaticamente.

MIGRAÇÃO
Se houver dados antigos fictícios não editados, o aplicativo troca o imóvel pelo contrato real e mantém despesas e configurações. Se houver edições das parcelas antigas, não as substitui. Os registros locais existentes não são apagados. Em Ajustes > Carregar contrato, é possível importar as 41 parcelas após fazer backup.

AVISO DE PUBLICAÇÃO
O código no GitHub Pages é público e contém valor do imóvel, cronograma e imóvel identificável, mas não CPF, RG, endereço residencial ou telefone. O armazenamento continua local, sem contas ou sincronização.
